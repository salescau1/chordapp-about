# chordapp-about

Sumber konten layar **About** aplikasi ChordApp.

- `about.txt` — teks yang ditampilkan di About. Plain text, UTF-8.
- Disajikan ke app lewat `raw.githubusercontent.com` sebagai `text/plain`.
- Repo harus tetap **publik** agar raw bisa diakses tanpa token.
- Edit `about.txt` lalu commit; app akan menariknya saat refresh (cache-first).
